第二幕
看不见的头顶
   · · ·    /\_/\   ( •ᴥ• )∫
小狐狸使劲往上瞄，眼睛都快对到一起了，还是看不见。狐狸是看不到自己头顶的。
小狐狸：「我想事情的时候，头上有东西吗？」
清醒宝：「以前是一朵花，会转圈。」
小狐狸：「那它去哪儿了？」

第三幕
三扇新门
 +----+    +----+    +----+  | == |    | [] |    | ~~ |  | == |    | [] |    | ~~ |  +-o--+    +-o--+    +-o--+   Docs     Slides    Design           /\_/\        ( o.o )  >>>
写字的门里只有纸。放映的门里只有幕布，一页一页翻过去，哪一页都没有花。
画画的门里，小狐狸尾巴一扫，蘸到了颜料盘，地上拖出一串小花。
清醒宝：「这些不是那一朵。」
小狐狸：「嗯，这些是我尾巴画着玩的。」
亮着的那扇是放映门：你现在就在这扇门里。

困困宝破案

清醒宝把三扇门都跑了一遍，累得啪一下趴在被窝边上。
困困宝（眼睛都没睁）：「花没丢呀。」
清醒宝：「那它在哪儿？」
困困宝：「睡着了。花睡觉的时候会把花瓣收起来，从上面看，就只剩三个小点点。」
小狐狸把尾巴垫到两个宝脑袋底下当枕头。它头顶的三个点，一闪，一闪。
