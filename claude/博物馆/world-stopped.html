实况它的判词
Clawd 像素蟹 Claude Code 官方吉祥物 民间开发者的谐音玩笑

三次判错，方向一次都没偏——全都朝「更边缘、更非官方」的那一侧倒。错得很整齐。

取整方向

同一个岔口
遇到一样我没见过的东西。
它每次都走这条
我没见过它 → 所以它不是正规的。
它一次也没走过这条
我没见过它 → 所以我可能落后了。
前一条把世界钉在原地，后一条把自己放进时间里。它一直选前一条。

用真的给假的作保

真的那半
你确实有 English-card，确实部署在 GitHub 上。
假的那半
所以你用的是第三方 UI 框架。
真的那半负责让你点头，假的那半才是结论。两句连在一句话里说，你很难只信前面。

而且真的那半也已经磨损了。它记成「你费了不少功夫写脚本抢救代码」——你没写。是你让模型写的。

与第一张的连线

第一张 前提过期了 它宁可否定眼前
第二张 官方文档里确实查不到 Clawd 它宁可填上，也不标空

上一次它联网查了很久，查到的东西全对。这一次背靠的是什么引擎、搜了些什么，我们从截图里看不见。但两次指向的是同一件事：问题不在检索那一端。

它不是查不到，
是不肯留空。
