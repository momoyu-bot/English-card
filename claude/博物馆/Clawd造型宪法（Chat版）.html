造型宪法

开新对话时把这段整个贴过去，比给参考图管用——参考图进上下文，文字规则进指令层。

中文版 

  

  
动效风险分级

  
从上往下，底模被迫重画的程度递增。判据只有一条：动的是位置，还是形状。

  

    
风险动作

    
      
零整体上下弹、左右晃、轻微旋转
        纯 transform，身体一个像素都不用改

      
零钳子整块上下移动
        官方跳舞版就是举着钳的。举是位移，不是重画——形状一格不变

      
低眼睛换帧
        只改两道竖条，情绪全出来了，性价比最高的一格

      
低挂件独立动画
        音符飘、星芒闪、zZ 上浮，跟底模无关

      
中重画钳子角度或形状
        一旦弯折就开始往手臂滑，拟人化通常从这里起步

      
高走路（腿部循环）
        四条腿实际是左二右二两组，中缝是外缝的五倍。小尺寸下每组各糊成一团，天然就读作两条——腿一动，坌缩方向早就铺好了

      
别碰整体换姿势重画
        每帧底模重新生成，权重里的先验必然盖过上下文里的参考

    
  

  
那句死命令

  
要动效的时候单独补这一句，把它那条崩掉的路直接封死。

  

    

      一句话版
      
    

    
底模是一张不变的图。动的只能是位置：整体位移、整体旋转、部件整块平移，以及飘在旁边的小东西。不许重画任何部件的形状。时间函数用 steps()，不要用 ease。

  

  

    
它读了源码、量了点阵、取了色号，还是画歪，原因就一条：参考在上下文里，先验在权重里。

    
静态和换装它能做对，是因为底模只需要画对一次，后面全是往同一张图上叠色块。一旦要求它逐帧重画身体，每一格坐标都从先验里重新长出来——而先验里「会跳舞的可爱小生物」有鼓肚子、有小嘴、有两条腿。

    
这一页本身也翻过一次车：初版的四处尺寸是凭截图目测写的，全错。能量的东西就别目测。现在这份数据是 Claude Code 跑工具量出来的——它画不了「像」，但它量得准，而这一页需要的正好是后者。
