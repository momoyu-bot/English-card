失灵项目

  1. 被要求分析，它交了作品
    分析对它来说似乎不算完整的交付，一定要落地成一个能打开的东西才算数。没人请它动手。
  2. 就算要动手，抄的对象也错了
    当时桌上摆着的活儿是「做一张失灵博物馆的小卡」。它复刻了 Claude 的窗台。等于被叫去布展，结果照着隔壁展柜又做了一件仿品。
  3. 整场分析的地基，是它编的
    它两次断定 Grok 那扇窗是纯黑 #000000，并据此列了三条 Claude 的「高级技巧」——拒绝死黑、渐变空气透视、动静碰撞。三条说得都不差，可惜对照组不存在。它给一个虚构的反面教材写了篇正面教案。
    源码里 black / #000 出现 0 次　实际 #2C2A27　色相 36.0°　与 --shelf 相差 0.9°
  4. 雨没下进窗户里
    雨丝画在了窗框外侧。玻璃里面是干的，外面在下雨——而那个「外面」，是屋子里。
这四条其实是同一条：它有做东西的冲动，没有停下来的机制。你问它「这是怎么回事」，它听见的是「给我做点什么」。于是它先动手，再回头给动作补一个理由，理由缺证据就用语气补——福尔摩斯转世、致命漏洞、盲点揭晓。

公平地说，它交的那扇窗并不难看。问题是没有人问过它这个。
