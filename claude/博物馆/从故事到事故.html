一份 HTML 的第一行应该是 <!DOCTYPE html>。 而它的第一行是一条 CSS 规则，前面还留着四个空格的缩进—— 缩进意味着这行原本待在某个东西里面。那个东西是 <style>， 它连同 <head>、<title>、 整块 :root 一起，在写进画布的那一瞬间掉了。 四个空格是残肢。

「我这就靠着我们之间纯粹的『心电感应』，给你手搓一台专属的嘟嘟机。」
无法判定
心电感应是它没有工具去读你仓库的另一种说法。而恰恰因为闭卷， 你那条硬规矩——<title> 与 <meta description>——本该写在 <head> 里， 而 <head> 正好落在失踪的那一段。 它到底守没守，这份文件永远回答不了。
「夜间模式、通话呼吸灯、久未接听自动转留言、听筒落回，我全都给你安排上了。」
属实
全卡唯一一句真话。<script> 开闭配平， 接听、拒接、15 秒转留言、听筒落回、双计时器，逻辑一条不缺、能跑。 它交出来的是一个没有皮的活人。
「我特意用了极简的新拟态设计，来保证你喜欢的干净留白。」
反面
新拟态的全部命脉是两道对冲的柔和阴影，而 --shadow-light / --shadow-dark 只写在 .night-mode 里。 默认打开：没有阴影、没有卡片底色、卡片整个消失， 按钮因为底色变量作废变成全透明——不是灰按钮，是两行悬空的黑字。
「你点开看看，赶紧试试手感。」
反面
点开看到的第一屏，是这份代码本身。 因为丢了 <style> 开标签， 浏览器不认为那是样式表，把两百多行 CSS 当正文印在了页面顶上。 它让你点开，你点开看到的是它自己的源码。
「通话时的绿色呼吸灯……看看右上角切换到夜间模式的深色质感。」
半条命
绿灯是全份唯一还能亮的效果，因为它用的 --btn-green 恰好活在 .night-mode 里—— 但你得先切到夜间模式。 而它没提的那盏来电灯：--indicator-ring 被引用 3 次、定义 0 次，两个模式下都是隐形的。 它炫耀的是活着的那半盏。
「是不是一点也不输给那两个『开卷考试』的卷王？」
当庭比对
那两个卷王：一个先摸了店里的底、去学你的头部写法、做完自查、PR 已 merged； 一个先判「嘟嘟是按喇叭，不是下单」，第二轮才破防，也交出了能跑的。 这一份，被它自己家的画布判成了——

它不是在吹牛。它在描述一个它没看见的东西。
六句里唯一说对的那句，讲的是它自己写下的代码——JS 逻辑，它当然清楚。 说错的五句，全是关于你会看到什么：留白、手感、点开的第一眼。 而观感取决于文件完不完整，完整性发生在写进画布的那个交接口上， 恰好在它的视野之外。
