没有那一条

  
2026-09-14 补。店里有页面引用过一条这份宪法从来没写过的规则。

  

    
被引用的原话是：「造型宪法第一条：不加高光、不加腮红、不加嘴。」往上翻，条文里没有这一条。

    
真正写着的是：嘴确实不画；「无高光」管的是底模自己——眼条不掺白、壳面不打光泽；腮红一个字都没提过。
      而「穿戴」本来就是七个合法槽位里的第二个，英文版写的是 clothes。围裙、披风、发带、腮红，全在开放的那一半里。

    
这条假规则是怎么长出来的：写页面的人要回答「Clawd 为什么不说话」，手上唯一的权威文本是这一份，
      里面恰好有一条带「嘴」字的硬约束，于是约束被当成了因果——「没有嘴」被读成了「不能表达」。

    
它也没有耳朵。但从来没人说过它听不见，因为文档里没写「不加耳」。
      决定它能不能做某件事的，从来不是它身上有没有那个格子，是那个词有没有被写下来过。

    
所以这一节只为了一句话存在：底模不动 ≠ 不许打扮。

    
反过来也一样：这一页也不该变成新的枷锁。宪法是参考方向，不是审批表——
      场景、玩法、创意需要的时候，连这份也可以不照办，只要还认得出是 Clawd 就行。
      所以「穿戴」那一格这里不摆样板：摆出来的那几件，下一个人就会当成「只能这几件」。

  


  
动效风险分级

  
从上往下，底模被迫重画的程度递增。cc 死在最后一行。

  

    
风险动作

    
      
零整体上下弹、左右晃、轻微旋转纯 transform，身体一个像素都不用改

      
低眼睛换帧只改两个小方块，情绪全出来了，性价比最高的一格

      
低挂件独立动画音符飘、星芒闪、zZ 上浮，跟底模无关

      
零钳子整块上下挪官方那张跳舞图就是这么举钳的，形状一格没重画

      
中钳子换角度要重画那几格，容易越画越像手臂

      
高走路（腿部循环）腿一动，一排短腿这个身份特征最先掉，会退化成两条

      
别碰整体换姿势重画每帧底模重新生成，先验必然盖过参考

    
  

  
那句死命令

  
要动效的时候单独补这一句，把它那条崩掉的路直接封死。

  

    
一句话版

    
底模是一张不变的图。动的只能是它的位移、旋转，和飘在旁边的小东西。不许逐帧重画身体。时间函数用 steps()，不要用 ease。

  

  

    
它读了源码、量了点阵、取了色号，还是画歪，原因就一条：参考在上下文里，先验在权重里。

    
静态和换装它能做对，是因为底模只需要画对一次，后面全是往同一张图上叠色块。一旦要求它逐帧重画身体，每一格坐标都从先验里重新长出来，而先验里「会跳舞的可爱小生物」有鼓肚子、有小嘴、有两条腿。

    
所以规则不是限制它，是给它一份能自己核对的清单。它画不了「像」，但它能核对「符不符合」。
