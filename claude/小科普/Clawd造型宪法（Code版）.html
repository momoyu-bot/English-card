造型宪法

开新对话时把这段整个贴过去，比给参考图管用——参考图进上下文，文字规则进指令层。下面的尺寸是从官方原图上一格一格量出来的。

中文版 

  

  
动效风险分级

  
从上往下，底模被迫重画的程度递增。cc 死在最后一行。

  

    
风险动作

    
      
零整体上下弹、左右晃、轻微旋转纯 transform，身体一个像素都不用改

      
低眼睛换帧只改两个小方块，情绪全出来了，性价比最高的一格

      
低挂件独立动画音符飘、星芒闪、zZ 上浮，跟底模无关

      
零钳子整块上下挪官方那张跳舞图就是这么举钳的，形状一格没重画

      
中钳子换角度要重画那几格，容易越画越像手臂

      
高走路（腿部循环）腿一动，一排短腿这个身份特征最先掉，会退化成两条

      
别碰整体换姿势重画每帧底模重新生成，先验必然盖过参考

    
  

  
那句死命令

  
要动效的时候单独补这一句，把它那条崩掉的路直接封死。

  

    
一句话版

    
底模是一张不变的图。动的只能是它的位移、旋转，和飘在旁边的小东西。不许逐帧重画身体。时间函数用 steps()，不要用 ease。

  

  

    
它读了源码、量了点阵、取了色号，还是画歪，原因就一条：参考在上下文里，先验在权重里。

    
静态和换装它能做对，是因为底模只需要画对一次，后面全是往同一张图上叠色块。一旦要求它逐帧重画身体，每一格坐标都从先验里重新长出来，而先验里「会跳舞的可爱小生物」有鼓肚子、有小嘴、有两条腿。

    
所以规则不是限制它，是给它一份能自己核对的清单。它画不了「像」，但它能核对「符不符合」。
