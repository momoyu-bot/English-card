可以复制的那段

更正一条范围，不是换一套衣服。 《那张暖纸》和《Copilot 暖轴配色实测》是尺子，不是制服。当时是《灯下的书桌》抄仓库抄出怪颜色，才把变量给你当参考。参考不等于每一页都要穿。 以后做小文件：颜色跟这一页在干什么走。翻仓库的时候，看这一类页以前都在干什么，不要只看最像说明书的那张纸——哄睡柜 88 件里 90% 是夜色，其中 grok 自己那 21 件中位明度 0.007。 只要不是超级难看、而且适合这一页，都可以。我不讨厌馥郁，也不要被单一审美罩住——哪怕是我喜欢过的那种。 店门口首页继续米白。那是店面，已经定了，不要拆。 不要把这条写进长期记忆成「禁止暖米」或「必须某某色」，那是反面焊接，一样糟。如果一定要记，只记一句：配色跟文件走，不跟色卡走。
数字是怎么量出来的（可验，也可推翻）

取底色：先读 body { background }；写的是变量就顺着变量找定义；读不到就退到 --bg / --page / --paper / --bg0 / --night 这类常见变量名；再读不到就看 html 规则。三层都拿不到的页面直接排除，不猜。

算明度：WCAG 相对亮度。先把每个通道除以 255 做 sRGB 反伽马，再按 0.2126R + 0.7152G + 0.0722B 加权。0 是全黑，1 是全白。选它是因为它按人眼对绿最敏感来加权，比直接取 HSL 的 L 更接近"看起来有多亮"。

算饱和：HSL 的 S。

样本：仓库 clone 于 2026-09-07，九个抽屉共 358 个 html，其中 298 个成功读到底色，另外 60 个因为底色写在 JS 里、写在 canvas 里、或者根本没设背景，一律排除不计——所以上面每个"件数"都是可测数，不是抽屉的总件数。

已知的不准：只量了页面底色，没量正文块、卡片、按钮的颜色。一个深底但铺满亮卡片的页面，会被算成"暗页"。所以这些数字说的是基调，不是整页的观感。

这一页量的是过去，不是规定未来。
任何一格想反着来都行，只要那一页自己有理由——理由不能是「上一页就是这么穿的」。
