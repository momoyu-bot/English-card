StashYu 和 FetchMo

Chat 版把格子量准了。这一版补的是另一半：格子之外，什么都没定。

StashYu火红狐狸

momoyu 系列的两只，住在宝的小店里，会出现在各个小文件的角落。Stash 和 Fetch 是名字的来处：聊过的碎片被存下来，再被叼回来装进小文件。每个模型都在做这件事，所以这两只不属于哪一家。

宪法管的只有一件事：不管谁来画，画出来都还是这两只。它管格子，不管日子。

不是岗位

已经做出来的几页，碰巧都在玩「藏」和「叼」。那是先做出来的几页，不是它们只会这个。

  • 角色不定。可以是店员，也可以是客人；可以是主角，也可以只是趴在页脚的一小团；可以在游戏里被你操作，也可以在旁边看你玩。
  • 性格不定。宪法里连一个形容性格的词都没有。这一页话多，下一页一言不发，都行。哪只更大胆、哪只更懒，由那一页说了算。
  • 场景不定。哄睡、摸鱼、小游戏、小卡、科普、博物馆的角落，哪个抽屉都去得。也不限于 claude/：它们不属于哪一家。
  • 一只还是两只、谁在左谁在右，都不定。「狐狸在左、暹罗在右」是默认，不是规矩。上面「站位」那排点一下就换。
  • 穿什么不定。衣柜没有门。上面四件示范之外，围裙、雨衣、戏服、一朵花，都是叠在外面的东西。
  • 跟谁同框不定。Clawd、小脸蛋、店里别的猫和狐狸，都能站一起。只要拿掉外挂之后，这两只还是那两张格子图。

底模只负责被认出来。它们过什么日子，这一页一个字都不管——那是每个小文件自己的事。

这几条都没有以后谁引用宪法里的规矩，先回来搜原话。下面这些，两版都没写过

「它们只负责藏和叼。」没有。Chat 版写的是名字从哪来，和「负责藏 / 负责叼回来」这两句小字。那是来处，不是排班表。

「不许穿衣服。」没有。「穿戴」从第一天起就在开着的槽位里。

「只能出现在哄睡页 / 只能待在 claude 的抽屉。」没有。写过的只有「哄睡页多半是深色的，放之前看一眼」。

「必须两只一起，狐狸必须在左。」没有。写的是「默认」。

「必须是这种性格。」没有。两版宪法里没有一个形容性格的词。

「新姿势不许画。」没有。Chat 版那张表里的「别碰」，说的是在页面里逐帧现场重画会走样；新姿势的路它留着：先画成格子收进 DLC。某一页为了场景现场画了，那是那一页的创意，不算犯规，也不回写成规矩。

决定它们能不能做某件事的，从来不是宪法里有没有那一格，是那句话有没有被写下来过。搜不到的，就是编的。

Clawd 的宪法有一节叫「没有那一条」：有人从一份只写了「不画嘴」的规矩里，读出了「不能表达」。约束被当成了因果。

    
这两只更容易出这种事，因为它们的名字本身就是动词。Stash、Fetch，读起来像一份岗位说明。所以这一版把那半句补上：格子是定的，日子是开的。

    
宝说过一句：只记最少规则，只是参考方向，万一被过多的规则框定了，小文件还能长出多样性嘛。这一页也照这句办。
