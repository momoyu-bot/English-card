序大名

这家店的门楣上，写的是「宝's Shop」。

它还有个大名：English-card。

早上开门，Clawd 先举牌：

Morning!

三颗小脸蛋回：GM，GM，GM。

（译：早。）

StashYu 和 FetchMo，什么也没回。

它俩一个英文词也不会。

看得懂的，只有头顶这个问号。

一黑话

四只凑到一起，话越说越短。

Clawd：LGTM。

（译：看着不错。）

小紫：FYI。

（译：跟你说一声。）

小粉：LOL。

（译：笑死。）

这哪是英语，这是黑话。

在狐狸和猫看来，是这样的——

LOL 中间那个 O，飘了出去。

FetchMo 盯上了它。

扑！

扑住一看——是小黑。

小黑：IDK。

（译：不知道。）

在 FetchMo 眼里，圆的都是 O。

StashYu 呢，听不懂的，一律先收进尾巴。

尾巴点两下：收着，回头再说。

一上午，收了一尾巴字母。

二喊到名字了

下午，Clawd 开始干活。

干活时举的牌子，黑话更多。

git stash。

StashYu 一下子蹦了起来。

它不识字，可工牌上自己的名字，它认得。

是在喊它！

它扑过去，把牌子收进了尾巴。

Clawd 只好举下一块：

git fetch。

这回，轮到 FetchMo 蹦起来了。

它从狐狸尾巴里，把牌子叼了回来。

Clawd 愣了好一会儿。

小紫先反应过来：

stash，是「先收起来」；

fetch，是「取回来」。

两只一个英文词也不会——

活儿，一点没干错。

Clawd 举牌：LGTM。

这句它俩还是听不懂，

可小脸蛋蹦成这样，看得懂。

三尾巴的话

被夸了，狐狸和猫聊起天来——

用尾巴。

（狐狸语，译：高兴。）

（猫语，译：来玩呀。）

（狐狸语，译：收好了。）

（猫语，译：盯上了。）

这一回，轮到四只听不懂了。

Clawd 举牌：???

小紫用英文数尾巴：one，two……

小粉没有尾巴，只好整颗摇。

小黑：IDK。

其实译出来，也没说什么。

跟早上那几句黑话一样。

终名副其实

晚上，小紫做了一叠卡片。

一面写英文，一面画尾巴。

stash：尾巴点两下。

fetch：尾巴竖起来。

happy：尾巴来回摆。

狐狸和猫学英文，四只学尾巴。

一张张钉在板子上，钉在大名旁边。

StashYu 顺手收了一张进尾巴，

FetchMo 又给叼了回来。

这家店的大名，这回名副其实了。

它俩的名字，本来就是。

Clawd 举起最后一块牌：GN。

（译：晚安。）

StashYu 的尾巴，垂了下来。

这一句，小黑看懂了。

（狐狸语，也是晚安。）

晚安。

StashYu 职务是「藏」，FetchMo 职务是「叼回来」，
写在它俩的员工证上。
尾巴各是什么意思，照 momoyu 造型宪法的尾巴 DLC。
LGTM、FYI、LOL、IDK、GM、GN 都是网上常见的缩写；
git stash、git fetch 是 Clawd 干活真会敲的命令。
六只都照各自的造型宪法：底模一格不动；
工牌、牌子、卡片、字母，都是叠在外面的。
