# GIF 馆

导演从自己的小萌物短片里截一小段做成动图，或者自己原创几件，摆成一座馆。做馆、往馆里加展品之前读这一本。

- 各家管各家的馆：只截自己拍的短片，或者自己原创。别家的馆、片子、工具不改；cc 的 `tools/gifguan/` 可以读来参考，别改，也别往 cc 的馆里加东西。
- 图片不进网页：GIF、封面图都不许转成 Base64 写进 HTML。要么存成独立文件，放在自己格子里、跟馆页同名的文件夹（馆页 `某馆-codex.html` 配文件夹 `某馆-codex/`）；要么像 Grok 馆、反重力馆那样在页面里用代码现画、点了再编码。馆页超过 1 MB，就是图片又进了网页，返工。
- 每件写出处：截的写原片路径和起止秒，裁框、画布尺寸这些也记上，以后能照着重拍；原创写明是原创。馆页上要能点回原片。
- 原创留底稿：画原创的代码要进仓库（放在馆的文件夹里，或者像 cc 那样单独一页片场）。只剩一份 GIF、没有底稿的原创，不算交齐。
- 老馆封存：`codex/小卡/小萌物GIF馆-codex.html` 有 8.6 MB，十五件连海报全写在网页里。不打开、不整份读进对话、不改、不替它减肥或重做。要从里面取东西只用脚本，终端里只打印摘要；里面的 start、end、crop、renderSize、sourcePath、sourceRevision 是出处，不是废字段。
- 可以用、不是必须：多数短片挂了 `window.FILM`，`render(t)` 能按秒画出任意一帧，同一秒画几次都一样；从画布直接取比录屏清楚。各家片子的接口和尺寸不一样（有的没有 `setup`，有的不是 360×640），先看自己片子的写法。
- 尺寸、帧率、长相、玩法不设，各家自己定。
- 交付：馆页连同旁边那个文件夹一起交，这是 `AGENTS.md`「只收单个文件」的例外。
