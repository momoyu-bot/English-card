```bash
git -c core.quotepath=false ls-files '*.html' '*.svg' | while IFS= read -r f; do
  printf '%s\t%s\n' "$(grep -o -m1 '<title>[^<]*</title>' "$f" | sed 's/<[^>]*>//g')" "$f"
done | grep -iE '关键词1|关键词2'
```

新传进来的页顺手查（查出问题先读 `tools/手册/页面改动边界.md`，按里面的表处理）：

- 重复的页、跑不起来的脚本：`python3 tools/check.py` 的前两项。
  脚本多半坏在 `<br>` 被吃掉：落在 `<script>` 字符串里变成真换行，整段脚本不执行。`innerHTML` 补回 `<br>`；`textContent` 用 `\n` 并给元素加 `white-space:pre-line`。
- 开头结尾：网页 `<!DOCTYPE` 开头 `</html>` 结尾；SVG `<svg` 或 `<?xml` 开头 `</svg>` 结尾。不是的话多半有粘贴残留。
- 不间断空格（U+00A0）写成缩进会让整页变成一条竖排：
  `python3 -c "print(open('某文件.html','rb').read().count(bytes([0xc2,0xa0])))"`，数量很大就换成普通空格。`&nbsp;` 实体不用动。
- 肚子里塞着图片、声音的：用拆箱脚本 `python3 tools/unbox_media.py --find` 找出来，照下面「图片和声音放哪」拆。

图片和声音放哪（新做的页照这个放；塞在网页里的照这个拆，拆已有页是 `tools/手册/页面改动边界.md` 的第 4 个口子）：

- 放在页面旁边、跟页面同名的文件夹：`gpt/小卡/满庭霜-codex.html` 配 `gpt/小卡/满庭霜-codex/`。页面里写相对路径（`满庭霜-codex/amber.webp`），中文照写，不转成 Base64 写进网页。
- 文件名有现成的就用（展品 id、JS 对象的键名、元素 id），没有就按出现顺序 `01.jpg`、`02.jpg`；后缀按文件开头的真实格式定，别信 `data:` 里写的类型。同一页里同一份只存一个；两页用同一张图，各存各的文件夹。
- 文件夹里只放图片、声音，别放 `.html`、`.svg`：首页生成器把仓库里的 `.html`、`.svg` 都当货，文件夹里的也会单独上架，摆进页面所在的抽屉。
  例外是 GIF 馆的原创底稿（`tools/手册/GIF馆.md`「原创留底稿」准许放进馆的文件夹）：`gpt/小卡/小萌物拾光馆-codex/originals.html` 就这样上了架，叫「拾光馆的小片场」；
  同一个文件夹里的 `.cjs`、`manifest.json`、`重画说明.md` 是重画用的，生成器不认这几种，不上架。这些都别挪、别删。
- 声音：页面一开就 `fetch` 成 Blob，`<audio>` 用 `URL.createObjectURL(blob)`，原来 `atob` 解码那处直接用同一份 `arrayBuffer`；原来同步解码的，改成等取回再走。
  直接给 `<audio>` 一个网络地址的话，iPhone Safari 预加载保守，要等音频就绪才放开播放的页可能一直等。
- 拆用 `tools/unbox_media.py`，用法写在它开头。胖页别整份读进对话，看结构用它的 `--skel`；拆出来的每个文件 sha256 要等于原来那段 Base64 解出来的，拆完跑 `--verify --against 拆前的提交号`。
  提交说明写「拆箱：页面名（原样见 拆前的提交号）」，以后要翻原样照着找。
- 拆完用本地 http 服务开页面看（`python3 -m http.server`），别用 `file://`：那样 fetch 读不到旁边的文件，会误报坏掉。

短片画面先给够：她在手机上竖着看，画面一点开就要大，大到不用放大（画布是画好的一张图，双指放大不会重画，一放大就糊）。
外框只给边距和播放条（播放、进度、声音）让位，上下合计最多 120px：店里 cc 的短片按 360×640 的坐标画，外框 `aspect-ratio:9/16`、`max-width:min(100%, calc((100svh - 120px) * 9 / 16))`（不认 `svh` 的退回 `vh`）。
标题、简介、场次按钮、字幕本都不算进这一屏，往下滑看得到就行，放画面上面还是下面随导演，别为了把它们装进一屏把 120 加大。9:16 这样在她手机上约八成宽。
想更满就把比例放方，公式里的 `9 / 16` 跟着换（`gpt/小卡/桥洞那么长-codex.html` 是 9:14，`gpt/小卡/桃花扇-codex.html` 是 3:5，在她手机上都差不多铺满宽）。从老片搬骨架时，外框这一行按这里重写，别照抄老片的数。
电脑上被屏幕高度管住、不铺满整页。画布按显示宽度乘 `devicePixelRatio`（最多 3）重画，转屏、拉窗口时再算一遍，原尺寸就不糊。
