# 新页面

机房手册的一本，目录在 [`tools/README.md`](../README.md)。

本册命令在云端用 Python 3.13 的 `python3`；Windows 把 `python3` 换成 `py -3.13`。

查同类的命令（`gemini/摸鱼/雷霆摸鱼.html` 就是做完才发现早有的）：

```bash
git -c core.quotepath=false ls-files '*.html' '*.svg' | while IFS= read -r f; do
  printf '%s\t%s\n' "$(grep -o -m1 '<title>[^<]*</title>' "$f" | sed 's/<[^>]*>//g')" "$f"
done | grep -iE '关键词1|关键词2'
```

新传进来的页顺手查（查出问题先读 `tools/手册/页面改动边界.md`，按里面的表和授权要求处理）：

- 重复：`python3 tools/check_dupes.py`。
- 开头结尾：网页 `<!DOCTYPE` 开头 `</html>` 结尾；SVG `<svg` 或 `<?xml` 开头 `</svg>` 结尾。不是的话多半有粘贴残留。
- `<br>` 被吃掉：落在 `<script>` 字符串里整段脚本不执行。扫 `python3 tools/check_scripts.py`，没输出就干净。
  `innerHTML` 补回 `<br>`；`textContent` 用 `\n` 并给元素加 `white-space:pre-line`。
- 不间断空格（U+00A0）写成缩进会让整页变成一条竖排：
  `python3 -c "print(open('某文件.html','rb').read().count(bytes([0xc2,0xa0])))"`，数量很大就换成普通空格。`&nbsp;` 实体不用动。

小萌物短片（一张 canvas 画到底的那几部，多在 `claude/小卡/`，哄睡夜那部在 `claude/哄睡/`）：页面里「导视频用的口子」别拆，要导的时候就用它。
交之前用这个口子让程序把整部每秒 30 格逐格 `FILM.render(t)` 跑一遍（是程序跑，不是一格格截图看）：哪一格报错，片子就停在那一秒，再点播放也过不去
（10-22《今日份的困》停在 0:59，是局部变量跟画笔函数同名）。印样只抽几格，抽不到。

短片画面跟着屏幕走：手机竖着一屏装得下画面和按钮，电脑上被屏幕高度管住、不铺满整页，三倍屏上不糊。
店里 cc 的短片按 360×640 的坐标画，外框 `aspect-ratio:9/16`、`max-width:min(100%, calc((100svh - 120px) * 9 / 16))`（不认 `svh` 的退回 `vh`），
画布按显示宽度乘 `devicePixelRatio`（最多 3）重画，转屏、拉窗口时再算一遍。比例不是非 9:16 不可，更方的也行。
别照某一台手机的尺寸写死：10-31 那轮只许按一款手机检查，她看着反而不合适；画布写死 390×480 又不按清晰度画，在手机上糊（`grok/博物馆/请再进来-build.html`）。
截图别只看一种宽度，电脑也看一眼。
