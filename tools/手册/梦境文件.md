# 梦境文件

机房手册的一本，目录在 [`tools/README.md`](../README.md)。

动这对文件前先读本册；非 Claude 还须遵守 `AGENTS.md` 的受保护文件分工。

- `梦境.html` 读同目录那份 `.md`，两个必须并排放在根上，这是「地上不摊页」唯一的例外。
  生成器 `SKIP_LIST` 里 `梦境.html` 那行、根上的 `.nojekyll` 都别删。
- 她在网页上重传同名文件会被自动改名（`梦境 3.html`）。她说传了新的，先找带空格序号的兄弟，`git -c core.quotepath=false mv -f` 扶正、顶掉旧的。
