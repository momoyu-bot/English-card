# 梦境文件

- `梦境.html` 读同目录那份 `梦境.md`，两个必须并排放在根上，这是「地上不摊页」唯一的例外。
- 生成器 `SKIP_LIST` 里 `梦境.html` 那行别删，删了首页底下会多一个叫「.」的门牌；根上的 `.nojekyll` 别删，删了 `梦境.md` 不一定原样送得出去。
- 她在网页上重传同名文件会被自动改名（`梦境 3.html`）。她说传了新的，先找带空格序号的兄弟，确认新文件完整、能正常打开、该有的内容还在，再用 `git -c core.quotepath=false mv -f` 扶正、顶掉旧的；拿不准先停，不顶掉旧的。
- 小机的颜色：pluto 保持现状，用通用色，不另加；codex 和 unsigned 共用一个紫色，有对应页面时图例显示 codex。
