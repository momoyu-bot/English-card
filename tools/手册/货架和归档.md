# 货架和归档

机房手册的一本，目录在 [`tools/README.md`](../README.md)。

分类、导入、整理前先读本册；非 Claude 改已有文件，先按 `AGENTS.md` 取得授权，下面的挪放办法不是额外许可。

- 五台小机共用同一套抽屉，按这个顺序：
  哄睡 / 摸鱼 / 小游戏 / 小卡 / 购物车 / 博物馆 / 小科普 / 打捞机 / 显影 / 盲盒。
- 地上不摊页，分类只看文件夹名。换货架 = 把文件挪进另一个抽屉；导入的页直接放进抽屉；别复制一份假装挂两处。
- 早安归哄睡，障眼法归摸鱼。小游戏是摸鱼的升维柜，她没点名别自己升。
  小卡是带着故事的卡；博物馆只收事故（残骸、翻车现场），带故事的哄睡页还是哄睡。
- 盲盒是正经货架，不是待办箱：归不了类的、量太少的放这儿。它永远该有货，别清空。
- `unsigned/` `pluto/` 平铺，不建抽屉。`unsigned/` 不再收新文件。
- `pluto/` 放 Arena 对战里拿到的页，谁写的都放这儿，揭晓了也不挪。pluto 不是模型名。哪些是 Arena 的她自己说。
  `pluto/README.md` 是她写的铭牌，别让 Grok 改。
- 顶层按「从哪段对话捞出来的」分，不按谁写的，别按文风挪。唯一例外：`grok/博物馆/女仆小螃蟹 Tamagotchi 小机.html`。在店里现做的新页按做它的壳放：Claude Code 和 claude.ai 做的进 `claude/`，Grok 的进 `grok/`，反重力的进 `gemini/`，Codex 的进 `codex/`，芯是哪家的模型都一样。
- `gemini/失误捞claude鱼/` 是事故合集：不合并、不改名、不动 001–009 编号；生成器 `SUBFOLDER_CAT` 那条别删。
- 每个抽屉里的「（把页面传到这里）.txt」不能删，少了就补回来：GitHub 不留空文件夹，靠它撑住。
- 旧抽屉 `失灵博物馆/` `赛博购物车/` `科普/` `凭证/` `障眼法/` 不重建。根上没有 `gpt/`。
