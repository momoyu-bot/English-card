# 页面改动边界

页面可见的内容、布局、配色、逻辑是原文，哪台小机的都不动。`<title>`、`<meta name="description">`、SVG 的 `<desc>` 可以改。
很多「有问题」的页是藏品不是待办，别去评价、修掉它们。`claude/` 的页觉得不对可以先问她；别的小机的不主动挑。
能动原文的只有下面三个口子。

**1. 页面坏了，按抽屉：**

| 抽屉 | 怎么办 |
| --- | --- |
| 博物馆 | 不修，那是留下的笑话 |
| 哄睡 / 小游戏 / 摸鱼 / 小科普 | 直接修 |
| 购物车 / 小卡 / 盲盒 / 显影 / `pluto/` / `unsigned/` | 先问 |
| 打捞机 | 默认不用管；她点名改翻译版时，按 `tools/手册/打捞机翻译版.md` 办 |

- 只修让它不能用的那一处。要补文案（比如被吃掉的 `<br>`），补的是原作者本来的意思，不自己重写。
- 两类先不修。只在聊天窗里能用的（扫出来报 `sendPrompt is not defined`）不用管；外链卡住白屏的那两百多个等她点名：
  `<head>` 里的外部字体、`cdn.tailwindcss.com` 这类地址连得上却一直不回应，挡住了渲染（真断网反而不白屏：请求当场失败，页面跳过它接着画）。
- 修好一个，去 `claude/小科普/哪些页面打不开.html` 改一条。

**2. 错别字：**只补回被改坏的；改对的、她有意重写的、标题与正文一致的都不动，拿不准先问她。
`grok/` 的由 Grok 按她本轮要求改，别家不代改；好笑的罗列进 `claude/博物馆/没有一个肯哄.html`。
别把物证当错字，生僻不等于错：`grok/盲盒/谋杀奶茶案.html` 的「馥苫白」；`gemini/博物馆/赛博遗迹入藏小卡.html` 的哄睡词表，连划掉的那个正确的「哄睡」也是展品；
`claude/博物馆/馥芮白连环误认案.html` 列的「苫」「苪」「苕」「苔」「芪」「茗」。怎么扫、Grok 报的字怎么核，见 `tools/手册/错别字怎么扫.md`。

**3. 缺标题、附注或外套：**标题、附注按 `tools/手册/名字和附注.md` 的分工补；外套只给 `claude/` 直接补，补法见 `tools/手册/裸奔怎么补.md`。
