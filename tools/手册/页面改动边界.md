# 页面改动边界

机房手册的一本，目录在 [`tools/README.md`](../README.md)。

动已有页的原文、标题、附注、错字或外套前先读本册；非 Claude 先按 `AGENTS.md`「只加不改」取得授权。本册的「直接修」「直接补」不能越过它，受保护文件仍按 AGENTS.md 的分工。

页面可见的内容、布局、配色、逻辑是原文，哪台小机的都不动。`<title>`、`<meta name="description">`、SVG 的 `<desc>` 可以改。
很多「有问题」的页是藏品不是待办，别去评价、修掉它们。`claude/` 的页觉得不对可以先问她；别的小机的不主动挑。
能动原文的只有下面三个口子。

**1. 页面坏了，按抽屉：**

| 抽屉 | 怎么办 |
| --- | --- |
| 博物馆 | 不修，那是留下的笑话 |
| 哄睡 / 小游戏 / 摸鱼 / 小科普 | 直接修 |
| 购物车 / 小卡 / 盲盒 / 显影 / `pluto/` / `unsigned/` | 先问 |
| 打捞机 | 不用管 |

只修让它不能用的那一处。只在聊天窗里能用的不用管；外链卡住白屏的那两百多个等她点名。

**2. 错别字，按小机：**`grok/` 的不改，好笑的罗列进 `claude/博物馆/没有一个肯哄.html`；
`claude/` `gemini/` `copilot/` `unsigned/` 的照 git 里的原件直接补回。`<title>`/`<meta>` 里的错字哪格都直接改。
别把物证当错字：`grok/盲盒/谋杀奶茶案.html` 的「馥苫白」、`gemini/博物馆/赛博遗迹入藏小卡.html` 的哄睡词表、
`claude/博物馆/馥芮白连环误认案.html` 里的冷僻字都不动。生僻不等于错。怎么扫、Grok 报的字怎么核，见 `tools/手册/错别字怎么扫.md`。

**3. `claude/` 的页裸奔**（只管 `claude/`）：没标题、没附注、没外套的直接补。
外套色值只认 `claude/小科普/chat_env_css_variables_probe.html` 里的 `:root`。补法见 `tools/手册/裸奔怎么补.md`。

改标题或附注，继续读 `tools/手册/名字和附注.md`；获准修坏页，继续读 `tools/手册/页面坏了.md`。
