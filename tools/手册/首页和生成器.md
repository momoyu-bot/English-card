# 首页和生成器

## 先守住这几条

- 首页清单由 `tools/build_index.py` 生成，在 `LIST:BEGIN`/`LIST:END` 之间，不手改。push 后工作流自己重算，连同总机线路表和小萌物画法合订本。
- 生成器必须是断网也能跑的完整源：不整份重写，不改成去外网下载。
- 首页是纯 HTML，打开时不发任何网络请求；清单不靠脚本，关了 JS 也是全的。
- 首页的方向是「像一间小店，不像网盘」，怎么做不设限。改样子前先读 `index.html` 里「改这里的人注意」那段注释：iPhone 上那些坑（吸顶、状态栏、`<summary>`、淡入、字体）都写在那页的注释里，这里不抄。

## 生成器

- 本地重算：`python3 tools/build_index.py`；只检查是否过期加 `--check`。
- 每张表（`ORDER` `PALETTE` `DISPLAY_NAME` `CAT_ORDER` `FLAT_FOLDERS` `SKIP_LIST` `SUBFOLDER_CAT`、总机那几张）怎么用，写在脚本里各自上面的注释。改之前先读那几行。
- 加一个平铺顶层（像 `pluto/`）要改三处：`ORDER`（插在 unsigned 前）、`PALETTE`、`FLAT_FOLDERS`。
- `tools/` 整个目录不上首页。
- `tools/小萌物画法.txt` 是 `tools/build_huafa.py` 抽出来的，别手改；抄哪几段、怎么换，看脚本开头的说明。
  本地跑 `python3 tools/build_huafa.py`，只查过没过期加 `--check`。哪一页抽不出来，那一段会换成一句「去翻原页」，工作流不红。

## 首页的样子

- 她嫌过三处：整体像网盘、货架名太重、货品的中文局促。当时的落地值在 `claude/小科普/首页是一次次调出来的.html`，照不照抄都行。
- 淡入有没有被加回去，判断标准是：把 JS 和 CSS 动画全关掉，每个名字都还要看得见。
- 那段注释第 5 条「把截图缩到很小再看」，用这行缩到 150 像素宽：

  ```
  python3 -c "from PIL import Image; im=Image.open('a.png'); im.resize((150,int(im.height*150/im.width))).save('tiny.png')"
  ```

- 她是「添加到主屏」全屏打开的。改完首页的样子要让她删掉主屏图标再加一次，不然看到的是旧页。
- 门楣上的梦境记号（`.lamp`）是手写的，不归生成器管，改前读那段 CSS 注释。

## 工作流和闸门

- 闸门（工作流里「店务文件还在不在」那一步，在生成清单之前跑）守着 `tools/build_index.py` `梦境.md` `梦境.html` `CLAUDE.md` `tools/README.md` `AGENTS.md`
  和 `tools/手册/` 里的每一本：掉到下限以下，就从历史里捞回最近一个够大的版本一起提交，不红。
- 下限只防整份被写成空壳，不是体重线，数字写在工作流里。笔记和手册别瘦到它以下
  （`CLAUDE.md` 3000 字节、`AGENTS.md` 300、目录页 1000、手册每本 200），不然会被捞回旧版。
- 手册新开、删掉、并掉都不用改工作流：有几本守几本，删掉的那本不会被捞回来。
- 改工作流前先读它自己的注释，坑都写在出事的那几行旁边。
