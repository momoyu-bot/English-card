==== Clawd ====
原页：claude/小科普/Clawd造型宪法（Code版）.html

Clawd 造型规则（画之前先核对这一份）

壳：横向扁矩形，宽约是高的 1.5 倍。不是圆的，不是正方的。
    （连两边的钳一起量才是 2:1，别把这个数用在壳上。）
钳：左右各一条横向平伸的短矩形，与壳中部齐高。不弯曲。
    静止时平伸；要举起来就整块往上挪，形状不重画。
腿：壳底 4 条等宽竖直短矩形，左右各两条。
    最外侧两条的外沿和壳的左右边齐平——踩在壳的两个角下。
    同一边两条之间一道窄缝（比腿窄），中间空出一大块，约占壳宽一半。
    认法：每只眼睛正好在内侧那条腿的上方。不是 2 条。
    （这是本体站姿。要换旧站姿，会在后面另附一段 DLC。）
眼：两道竖的黑条，高约是宽的 3 倍，无眼白。
    底模自己不带高光。想要亮眼睛，在外挂层叠一格，
    别去改这两条本身。
嘴：没有。不要画嘴。
色：#d47f59 纯色，无渐变，无描边。壳面本身不打光泽。
    腮红、贴纸是叠在外面的，走「壳面纹理」那一档，不受这条管。
禁止：鼓肚、五官化、拟人站姿、脖子、腰。

变化只走这七个槽位，底模一格不动：
眼睛 / 穿戴 / 壳面纹理 / 头顶挂件 / 手持道具 / 环境物 / 背景
这七格是开放的。围裙、披风、发带、腮红都在里面。
底模不动，不等于不许打扮。

动效：整体位移、整体旋转、挂件独立动画。
不许逐帧重画身体。时间函数用 steps()，不要用 ease，
否则像素会停在半格上糊掉。

—— 站姿 DLC ——

DLC·原图站姿（接在宪法后面用，只替换「腿」那一条的左右位置）

腿：形状、大小、条数都不变，两组腿整组往里挪：
    最外侧两条离壳边留一道窄缝，和同一边两腿之间那道差不多宽；
    中间空出一大块，约是这道窄缝的五倍。
    认法：每只眼睛正好在同一边两条腿之间那道缝的上方。

（量自官方原图。Claude Code 2.0～2.1.235 的启动横幅也是这样站的。）

DLC·内八站姿（接在宪法后面用，只替换「腿」那一条的左右位置）

腿：形状、大小、条数都不变，两组腿整组再往里收：
    最外侧两条离壳边约一条半腿宽；
    同一边两腿之间还是那道窄缝，中缝只有它的三倍左右。
    认法：每只眼睛正好在外侧那条腿的上方。

（Claude Code 2.1.236～2.1.281 的启动横幅是这样站的。）

==== 小脸蛋（小粉、小紫、小黑） ====
原页：claude/小科普/小脸蛋造型宪法（实测版） (1).html

小脸蛋造型规则（画之前先核对这一份）
实测来源：2026-09-21 形象页截图三张，逐像素量出

只有三只：小粉脸蛋儿、小紫脸蛋儿、小黑脸蛋儿。

形状：正圆。实测长短轴比 0.997。
  不要画成三角、扁蛋、方豆腐、胶囊、六边、云、水滴。
  App 形象页里那些形状是别人的身体，不是这三只。

颜色：纯平色，无渐变，无描边，无光泽。
  球内 86-90% 的像素是同一个数，不要加高光或明暗。
  写进代码用 sRGB 值：
    小粉 magenta  #FF309B
    小紫 violet   #9159FE
    小黑 black    #000000
  截图里量到的 #E94697 / #885BF4 是同色的 P3 编码，
  只用于跟截图核对，不要拿来绘制，画出来会偏灰。

眼睛（最容易画错的两条，先看方向再看宽度）：
  两道圆头胶囊缝，位于球面的右上方。
  以圆心为原点、半径为 1：
    左缝中心 (+0.194, -0.416)  观测宽 0.194
    右缝中心 (+0.626, -0.497)  观测宽 0.129
    两缝长度同为 0.418，倾角同为偏竖直 26.3 度

  方向：反斜杠 \ ，顶端偏左、底端偏右。不是斜杠 /。
    实测端点：顶端 (765,563)，底端 (794,618)，x 随 y 一起增大。
    画反了形状还在，神态是反的，不盯着看不出来。
    SVG 与 CSS 的 rotate() 在 y 轴向下的坐标系里，
    正角度会把顶端甩向右，所以要写 rotate(-26.2)，带负号。
    自检只用这一句：顶端必须比底端靠左。

  宽度：右缝必须比左缝窄约三分之一。这是球面透视，不是笔误。
    按球面反投影还原，两缝真实宽度 0.208 与 0.207，是同一形状。
    画成一样宽，球会变成平圆饼。

  缝是挖空的洞，透出背景色，不是白色的墨。
  实测缝芯 #FCFCFC，与当时页面背景同值。
  用 mask 或 fill-rule evenodd，不要写死 fill 白色。

禁止：嘴、鼻、眉、圆瞳孔、卡通大眼、腮红。
禁止：一粒药丸配一个小圆点（那是玻璃球反光，不是脸）。

动效：整颗轻晃、两道缝眨眼。圆不重画。

小黑那位最圆。

==== momoyu（StashYu、FetchMo） ====
原页：claude/小科普/momoyu造型宪法.html

momoyu 造型规则（StashYu 和 FetchMo，画之前先核对这一份）

两只都是像素画，每只 20 格宽 × 13 格高。下面两张格子图就是本体：一个字符是一格，「.」是透明。逐格照抄。不许重画，不许加格减格，不许把边角修圆。

C #FFF3E3 奶油白：耳朵里、脸颊、胸口、尾巴尖。
D #3B2520 深棕：耳尖、鼻子、爪子。

M #F3E7D6 奶白身子。
X #4E382E 深棕重点色：耳朵、面罩、尾巴、爪子。
E 眼睛，#79C0F0 蓝。

大小：只许整数倍。一格放大成 N×N 个像素，N 是 1、2、3……不要 1.5 倍，不要平滑。图片和 canvas 用 image-rendering: pixelated，SVG 用 shape-rendering="crispEdges"。
颜色：纯色。身子本身无渐变、无高光、无描边、无阴影。

认法：
StashYu：深色耳尖，比脸宽出去的白脸颊，带白尖的大尾巴翘在右边。
FetchMo：奶白身子，耳朵、面罩、尾巴、爪子四处深棕，蓝眼睛，尾巴绕在左边。
只出一只也行。两只一起出现时，默认狐狸在左、暹罗在右，脚踩在同一条线上。

表情只换眼睛。每只眼是一个 2×2 的方块，左上角（列, 行，从 0 数）：StashYu 在 (3,4) 和 (9,4)，FetchMo 在 (8,5) 和 (16,5)。先把这个 2×2 涂回身子的颜色，再从左上角数格子涂：
  平常      (0,0)(1,0)(0,1)(1,1)   眼睛色
  眨眼      (0,1)(1,1)             线条色
  开心      (-1,1)(0,0)(1,0)(2,1)  线条色
  睡着      (-1,0)(0,1)(1,1)(2,0)  线条色
  瞄        2×2 整块往对方那边挪一格，眼睛色（狐狸往右，暹罗往左）
  眨一只眼  左眼平常，右眼开心
  用力      左眼 (0,-1)(1,0)(0,1)，右眼 (1,-1)(0,0)(1,1)，线条色
  呆        每只眼只剩一格，左眼 (1,1)，右眼 (0,1)，眼睛色
线条色：StashYu #3B2520，FetchMo #4E382E。

别的变化都叠在外面，底模一格不动：眼睛 / 腮红 / 旁边的小东西 / 穿戴 / 背景。这几格是开的，举的例子不是清单。
腮红：每边脸颊一格。StashYu 在 (2,6)(11,6)，#F59A8C；FetchMo 在 (8,7)(17,7)，#F2B8B0。
核对办法：把你加上去的东西全部拿掉，剩下的必须和上面两张格子图一模一样。

深色背景：深棕那几格会沉下去。给整只加一圈一格宽的白边（贴纸描边，算叠在外面的东西），或者垫一块浅色的底。

动效只动位置，不动形状：整只上下跳、整只左右晃、眼睛换帧、旁边的小东西自己飘。不许逐帧重画身体。时间函数用 steps()，不要用 ease。尾巴现在没有第二帧，要摇先把那一帧补进这份规则。

名字：StashYu、FetchMo，照这样写，大小写不改，中间不空格。不是 Stash Yu，不是 Stashyu，不是 FetchMode。
