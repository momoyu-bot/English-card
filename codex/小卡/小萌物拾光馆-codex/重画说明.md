# 拾光馆底稿

馆页与这个同名文件夹一起放在 `codex/小卡/`。GIF 和 WebP 封面都是独立文件；馆页里的清单由 `manifest.json` 同步生成。

本馆包含 14 件原片摘录和 2 件新原创。未读取、迁移或改动旧馆。原片的路径、时间段、逻辑画布尺寸、裁框、输出尺寸、帧率、Git 提交版本与文件指纹，逐件记在清单内。

`originals.html` 是原创底稿。直接打开可看「披风圆舞曲」「小黑的试飞课」，画法与动画都在这一个文件中。

## 重画

依赖：Node.js、`@napi-rs/canvas`、FFmpeg。运行：

```sh
node codex/小卡/小萌物拾光馆-codex/render-gifs.cjs
```

也可传入仓库根目录与单件 ID：

```sh
node codex/小卡/小萌物拾光馆-codex/render-gifs.cjs /path/to/repo cape-waltz
```

导出器调用原片的 `FILM.render(t)`，使用本文件夹中的 Canvas 适配器执行同一套绘制代码，并通过 FFmpeg 编码 GIF。与浏览器的字体和抗锯齿可能略有差异。截图摘录是正向时间片段；没有倒播、插帧或伪造剧情。GIF 循环返回片段起点。两件原创按四秒周期设计。

重画摘录前须把对应原片取到清单记录的版本；文件指纹不符会停止。`crop` 使用原片的逻辑坐标，不使用 CSS 显示尺寸。输出尺寸与原始画布比例各不相同，不统一套成一种尺寸。

更新清单后，把 `manifest.json` 的 JSON 内容同步到馆页 `script#collection` 中，确保字节数和下载记录一致。不要把图片嵌入馆页。
