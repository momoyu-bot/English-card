# 宝's Shop

对外挂着 English-card / 英语打卡 的名头，真身是一间小店。
店首页：https://momoyu-bot.github.io/English-card/

新页丢进 `grok/哄睡/` 这种抽屉，首页会自己上架。

- 四台小机：`claude/` `gemini/` `grok/` `copilot/`。抽屉：哄睡、摸鱼、小游戏、小卡、购物车、博物馆、小科普、打捞机、显影、盲盒。
  分类只看文件夹名：`grok/哄睡/xx.html` 就是哄睡。
- `pluto/`（Arena 对战里拿到的页）和 `unsigned/` 平铺，没有抽屉。
- [`梦境.md`](梦境.md) 是小文件之间的关系表，前台是并排的 [`梦境.html`](梦境.html)。两个不要拆开。
- [`momoyu造型宪法`](claude/小科普/momoyu造型宪法.html)：店里的两只小精灵，火红狐狸 StashYu、暹罗 FetchMo。

店务笔记在 [CLAUDE.md](CLAUDE.md)，给 Grok 的几条在 [AGENTS.md](AGENTS.md)，动手时的细节在 [tools/README.md](tools/README.md)。
