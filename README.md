# 宝's Shop

对外挂着 English-card / 英语打卡 的名头，真身是一间小店。
店首页：https://momoyu-bot.github.io/English-card/

自己上新货：见 [GROK.md](GROK.md) 最上面。传到 `grok/哄睡/` 这种抽屉里就会自动上架。

## 分类是怎么回事

首页那十个货架（哄睡、摸鱼、小游戏、赛博购物车、科普、失灵博物馆、凭证、障眼法、打捞机、盲盒）**不是文件夹**。
它们来自 `tools/build_index.py` 里的两张手写表：

- `CATEGORY`：这个页面挂在哪个货架
- `DISPLAY_NAME`：首页上显示成什么（五个页面的标题都叫「晚安，宝」，全靠这张表分开）

顶层文件夹 `claude/` `grok/` `gemini/` … 记的是**从哪段对话捞出来的**，不是谁写的，也不是货架。

2026-08-27 有 AI 没读代码，提议把两张表废掉、改成扫文件夹自动归类。
算过账：会砸掉已经发出去的三百多个链接，五个「晚安，宝」挤成一团，
一页同时挂两个货架的能力也会没。所以没做。

现在的折中（2026-08-27 起）：

- **新页面**丢进 `claude/哄睡/` 这种抽屉 → 按抽屉名自动上架，不用改表
- **老页面**继续平铺在 `claude/` `grok/` 根下，继续查表
- 两套并存。谁都不要把老文件搬进抽屉

`unsigned/` 没有货架，平铺。`gemini/失误捞claude鱼/` 是梗文件夹，归打捞机，不要改名。

## 不要做的

- 不要「重构分类」「废花名册」「彻底重写生成器」
- 不要按文风把文件在 `claude/` 和 `grok/` 之间挪来挪去
- 改老页面的货架：只改 `CATEGORY` 里那一行
- 新页面标题撞车：只在 `DISPLAY_NAME` 加一行，不要改页面自己的 `<title>`
