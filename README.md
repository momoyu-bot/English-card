# 宝's Shop

对外挂着 English-card / 英语打卡 的名头，真身是一间小店。
店首页：https://momoyu-bot.github.io/English-card/

新页丢进 `grok/哄睡/` 这种抽屉，首页会自己上架。

- [`梦境.md`](梦境.md) — 小文件之间的关系表。做索引、串连、判断「这几页是同一件事」时对照这份。
  前台是并排的 [`梦境.html`](梦境.html)（首页门楣上店名旁边那枚捕梦网小记号点进去），
  它开着就去读同目录的 `梦境.md`，所以**改关系只改 .md 那一份，两个文件不要拆开、不要挪进抽屉**。

## 现在怎么分类

四台小机：`claude/` `gemini/` `grok/` `copilot/`。
抽屉：哄睡、摸鱼、小游戏、小卡、购物车、博物馆、小科普、打捞机、显影、盲盒。
`显影` 只开在 `claude/` `gemini/` `grok/`，排在盲盒前。`copilot/` 不加这一格。
地上不摊页。分类看文件夹名：`grok/哄睡/xx.html` 就是哄睡。

`unsigned/` 没有抽屉，平铺。它排在首页最后一格——那边已经不会再上传新文件了。
`pluto/` 也没有抽屉，平铺。放在 Arena（arena.ai）对战里拿到的小文件，
不管哪个模型写的都放这里，投没投票、揭没揭晓名字都行。
货架名不等于模型名——叫 pluto 不代表里面都是 Arena 上那个叫 pluto 的模型写的。
`gemini/失误捞claude鱼/` 是梗文件夹，归打捞机，不要改名、不要动编号。

首页清单由 `tools/build_index.py` 生成。不要手改 `index.html` 里那一段。
新页把名字写进自己的 `<title>`，附注写 `<meta name="description">`（一句中文，46 字以内）。
`DISPLAY_NAME` 是老页面留下的表，不要再往里加，已有的行也不要删。
两个页面门口同名，改各自的 `<title>`；生成器会先加后缀兜住。
`CATEGORY` 表现在是空的，别再往里加行。要换货架，把文件挪到另一个抽屉。

顶层文件夹记的是从哪段对话捞出来的，不是谁写的。不要按文风在小机之间挪文件。

## 不要做的

- **不要改任何页面的原文**：可见内容、布局、配色、逻辑，一个字符都不动。
  `<title>` 和 `<meta>` 不算原文，可以改。她当场点了某一页要改，听她的。
- 页面坏了修不修看抽屉：博物馆里的翻车和 bug 是藏品，不修；哄睡、小游戏、摸鱼、小科普坏了要修；
  购物车、小卡、盲盒先问她。
- 不要「重构分类」「废掉生成器」「彻底重写」`build_index.py`
- 不要清空盲盒，也别把它当成待办箱
- 不要再新建 `凭证/`、`障眼法/`、`赛博购物车/`、`科普/`、`失灵博物馆/`
- 不要删抽屉里的 `（把页面传到这里）.txt`
- 不要给 `unsigned/`、`pluto/` 建抽屉
- 不要按文风把 `pluto/` 的页挪进小机，也不要把小机的页挪进 `pluto/`。
  哪些是 Arena 的，她自己说
