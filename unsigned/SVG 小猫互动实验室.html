耳朵角度
这个值改变的是多边形顶点，顶点一动，耳朵就像在听八卦。
眼睛大小
圆形半径就是最直观的 SVG 参数之一，简单粗暴，适合教学。
身体圆润度
这是一个用 path 画出来的身体，改曲线控制点，轮廓就会变胖变瘦。
尾巴卷曲
尾巴是两段贝塞尔曲线拼出来的，特别适合讲“控制点为什么重要”。
描边粗细
stroke 越粗，线条越有卡通感；太细就像被现实打磨得没脾气。
第 1 步：先看最外层的 SVG 容器 SVG 不是一张死图，它是一个坐标系统。viewBox 决定你在多大范围里画东西。
<svg viewBox="0 0 800 540"> ... </svg>
第 2 步：身体、耳朵、眼睛其实都是图形拼出来的 你会看到 circle、ellipse、polygon、path 这些元素一起工作。所谓“画猫”，本质上就是把基础图元组合得像猫。
circle = 眼睛 / 鼻子 polygon = 耳朵 path = 身体 / 尾巴
第 3 步：调参数不是玄学，是改属性 比如眼睛半径改了，圆立刻变；尾巴控制点改了，曲线立刻弯。SVG 的妙处就在于它“听得懂属性”。
r 改变圆的半径 points 改变多边形顶点 path d 改变曲线路径
第 4 步：把“原理”换成“手感” 让用户拖一拖、试一试、看一看，理解速度会比念定义快得多。毕竟人类对抽象概念的耐心，通常短得像一只受惊的小猫。
