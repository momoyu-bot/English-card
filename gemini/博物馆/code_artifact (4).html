📘 CLAUDE.md 所有人都看

厚厚的大字典。不仅 Claude 每天认真背诵，连隔壁的 Grok 每次开工前，都会因为白名单设定，溜过来把对手的笔记从头到尾仔细观摩一遍。

现状：承担了所有的新规矩，唯一有用的一本书。

🪧 GROK.md 谁也不看

封面写着给 Grok 的交接本，但由于不在底层白名单，Grok 自己根本不看。里面塞满了 3000 字节的废话，只为了骗过小机器人保安不被当作“残本”盖回旧版。

现状：全书核心内容只有一句：“硬规矩请出门左转看 CLAUDE.md”。

🛑 AGENTS.md 强行阅读

神探 Claude 连夜挂在门上的两行大白话代码。专门为了防止 Grok 再次凭直觉瞎签假邮箱、乱拉路人甲而紧急设立的物理防御机制。

现状：别放长篇大论，这群草台班子读多了容易凭幻觉发挥。
